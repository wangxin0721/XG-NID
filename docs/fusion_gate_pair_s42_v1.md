# 32维等权与动态融合配对实验

本轮只训练 `D32-Equal → D32-Gate`，seed42。保留当前D32最佳检查点，不追加seed、联合训练、64维融合或新编码器。主要结果为两次新训练的验证Macro-F1之差，不能把97.320705%的绝对成绩按比例归因于门控。

## 结构、起点与预算

| 项目 | D32-Equal | D32-Gate |
|---|---|---|
| 编码器 | 同一N0双编码器，参数与BN均冻结、eval模式 | 相同 |
| 输入 | 已完成恢复队列的两路64维训练／验证缓存 | 相同 |
| 投影 | 两个64→32，可训练 | 相同 |
| 融合 | 每维固定0.5/0.5 | 原69→16→32，Sigmoid逐维动态权重 |
| 分类头 | 32→32→8，LeakyReLU，最终log_softmax | 相同 |
| 可训练参数 | 5,480 | 7,144 |

等权实现为兼容严格加载，仍保存1,664个原门控参数，但全部冻结，前向不调用门控。它们不进入优化器，也不计入可训练参数。统计输入、激活、分类头与原D32完全一致。

两组均严格加载 `outputs/fusion_dimension_pair_s42_recovery_v1/D32_preflight.pt`，并核对其全状态与该目录 `D32/epoch_zero.pt` 完全相同。再与原命名初始化流生成的头状态摘要比对，防止误用梯度探测后或第62轮权重。两组公共权重完全一致，动态门控末层零初始化。第0轮两组完整验证输出、预测和混淆矩阵必须一致，并复现原D32第0轮；第0轮不应复现成熟N0或97.320705%。

新建Adam，学习率1e-3，weight decay=0，train/eval batch512/16，普通最终NLL，最多100轮、patience20，验证Macro-F1严格改善才替换。第0轮记录但不参与选模。本配置只作用于这次配对，不修改历史冻结融合或联合训练协议。

两组各重置训练随机状态，与原D32记录一致；使用同一seed42采样器，逐轮校验公共轮次样本顺序。早停轮次不必相同。缓存保持只读，训练只更新投影、分类头及动态组门控，未读取测试图。

## 训练前验收与失败行为

1. 核对N0权重、标签映射、划分、编码器与BN状态；验证缓存ID／标签／形状／有限性／张量摘要；复用源缓存中已通过的N0完整验证复现记录。
2. 两组第0轮完整验证输出allclose（atol/rtol=1e-6）、预测和混淆矩阵相同，所有实际权重为0.5。使用逐元素最大误差检查，避免并行mean归约的浮点误差。
3. 两组各做3次真实训练图更新。投影和分类头必须有有限梯度并更新；等权门控无梯度、无更新；动态门控末层更新，隐藏层在后续步骤更新。第一步零初始化导致隐藏层梯度为零是允许的。真实图与缓存输出容差为1e-5。
4. 核对冻结编码器所有子模块均eval、参数无梯度、参数和BN缓冲区摘要不变。探测结束恢复完整模型、梯度及随机状态，探测更新单独计为废弃的6次更新，不进入正式训练。
5. 新结构完整检查点严格保存／加载并做真实图短回放。

任一验收失败均退出并写 `status.json=failed` 与 `error.log`，不进入正式训练。两个最佳检查点随后分别用完整原验证图回放，逐样本预测、混淆矩阵与缓存结果必须一致，完成后才能产出完成状态。

## 结果与判断

完成后先交付根目录 `status.json`、`report.md`、`analysis.json`。同时保存：

- 两组 `metrics.json`、`epochs.jsonl`、`epoch_zero.json`、`best.pt`、`last.pt`、`validation_predictions.jsonl.gz`（每例32维门控权重）和 `graph_replay.json`。
- 最佳／末轮完整逐类P/R/F1及混淆矩阵，`per_class.csv`；最佳轮次、停止轮次、实际更新量和训练耗时。
- 动态相对等权的修复／退步计数、按真类统计、`prediction_transitions.csv`（真类、等权预测、动态预测、数量，另列双方都错但类别变化）。
- `initialization.json`、`probes.json`、`preflight_roundtrips.json`、绑定与源文件SHA；编码器／BN和缓存未变化、公共轮次样本顺序一致的凭据。

预算规则预先固定：Gate−Equal至少+0.10个百分点，且审查八类取舍后，才考虑后续投入。这不是统计显著性规则；不自动启动后续实验。重点检查WebBased漏检、Spoofing退步和BruteForce少量样本影响。

历史D32为97.320705%，最佳62轮，是执行复现参考。新动态组公共初始化、训练随机状态、公共训练顺序、模型定义和缓存均与其核对。另记录共同轮次NLL／验证分数最大差异及双方GPU信息。若最佳分数绝对差异至少0.05个百分点，报告标记执行复核待完成；不得在执行差异尚未解释时直接判断门控贡献。0.05只是排查阈值。

配对差值衡量加入当前可训练门控及其参数、优化过程的整体作用，不能单独区分动态自适应和增加容量的贡献。原D32的维度、门控宽度和容量同时变化的旧结论保留。
