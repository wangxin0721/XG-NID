# E0-B512 结构对照与服务器执行

E0-B512 保留原 E0 单异构图编码器、GAT 和边属性，只将训练 batch 从16改为512。它用于补齐 E2-B512 的同 batch 结构对照。E0 431704 参数，E2 846800 参数；聚合、池化和分类头也有差异，因此两者差值不能全部归因于双分支或门控。

2026-10-21 用户要求开始此实验。已有其他实验测试结果可见，本实验登记为探索性结构补充对照，不属于预先盲测。选模只用验证集 Macro-F1，最后加载最佳检查点评价一次既有测试集。E3a 仍独立运行，不应中断。

## 固定条件

- seed42、Adam lr0.001、无学习率缩放，普通 NLL，无新增监督或类别权重。
- 原分组划分：107621/13446/13448；训练512，初始化与验证/测试 batch 均16。
- 最大100轮，验证 Macro-F1 严格提升，连续12轮无提升早停。
- E0 初始化必须复现原 E0 的 SHA256 `906e125925a8a2cc53a526602db0f047f76b1e41b8087c893f5cf1af41f64a6b`。E2 架构不同，不能要求两者初始化哈希相同。
- 完整训练轮211次更新；与 E2 相同轮上限不意味着早停后的总更新次数相同。
- 原训练器、模型、数据与已有输出保持原状，新增入口仅复用原加载器、初始化、采样器、评价与检查点函数。

## 执行

先将新增入口和配置提交推送。以下从已审核提交取出两文件，不切换服务器正在使用的工作树。将 `E0_COMMIT` 换成此次交付的提交号。

```bash
. /home/nzxn/miniconda3/etc/profile.d/conda.sh && conda activate wx
cd /home/nzxn/下载/WX/load/XG-NID
git fetch origin codex/r0-edge-preparation
E0_COMMIT=填写此次提交号
git show "$E0_COMMIT:scripts/run_e0_batch512.py" > /tmp/xgnid_e0_b512.py
git show "$E0_COMMIT:configs/e0_batch512.json" > /tmp/xgnid_e0_b512.json
python -B /tmp/xgnid_e0_b512.py --repo . --config /tmp/xgnid_e0_b512.json --mode check
```

check 仅核对元数据和文件字节，不导入模型、不接触 GPU。服务器文件需有原 E0-B16 和 E2-B512 的完整输出（配置中的路径保持原样）。

探测指定物理 GPU1，允许与已有作业共享；GPU 查询仅为瞬时记录，不代表资源预留或独占。它只读取真实训练图，检查六个 GAT 的边属性输入、边投影梯度和实际优化器更新；1次预热、3次计时更新。探测不评价验证/测试集。

```bash
python -B -u /tmp/xgnid_e0_b512.py \
  --repo . --config /tmp/xgnid_e0_b512.json \
  --mode probe --batch-size 512 --physical-gpu 1 --allow-shared-gpu \
  --output outputs/e0_batch_probe_b512_s42_shared_v1
```

仅在探测显示 `completed` 后，另行提交正式训练。入口会验证成功探测与当前配置、代码、运行环境和 GPU UUID 相符；已有目录拒绝覆盖，不自动重试或续训。探测的少量 batch 不保证全程显存上限。共享执行耗时不能作为独占加速基准。

```bash
if [ -e outputs/e0_batch_full_b512_s42_shared_v1 ] || [ -e outputs/e0_batch_full_b512_s42_shared_v1.log ]; then
  echo "已有正式训练目录或日志，请先检查。"
else
  nohup /home/nzxn/miniconda3/envs/wx/bin/python -B -u /tmp/xgnid_e0_b512.py \
    --repo . --config /tmp/xgnid_e0_b512.json \
    --mode full --batch-size 512 --physical-gpu 1 --allow-shared-gpu \
    --probe-report outputs/e0_batch_probe_b512_s42_shared_v1/summary.json \
    --output outputs/e0_batch_full_b512_s42_shared_v1 \
    > outputs/e0_batch_full_b512_s42_shared_v1.log 2>&1 < /dev/null &
  echo "$!" > outputs/e0_batch_full_b512_s42_shared_v1.pid
fi
tail -n 30 -F outputs/e0_batch_full_b512_s42_shared_v1.log
```

提交后台任务不等于训练启动成功。以日志中的 `E0 batch=512` 轮次指标确认进度，以根目录 `status.json` 的 completed/exit_code0 及 `E0/metrics.json` 确认结束。正式结果保存到独立 E0 子目录；同时保留最后和最佳检查点。
