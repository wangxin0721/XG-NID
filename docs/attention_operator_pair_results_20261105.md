## 收束判断

主要算子差值`GATv2−GAT = -0.111549个百分点`。
GATv2相对历史D32为-0.167814个百分点，相对当前CL-Multi为-0.357095个百分点。
本轮GAT本身比D32低0.056265个百分点，因此预算参照取D32：

`GATv2−max(GAT,D32) = -0.167814个百分点`。

继续投入要求97.420705%，本轮GATv2还差0.267814个百分点，未过+0.10个百分点的预登记门槛。
不因GATv2最佳发生在第147轮而追加训练预算，也不根据末轮回落后改动选模规则。
结论限于本轮单seed、输入、偏置匹配和从头训练协议，不证明GATv2在其他设置下普遍差于GAT。
成熟D32和CL-Multi经过不同训练流程，与它们的差值仅表示当前候选分数比较；算子收益应由本轮GATv2与GAT的匹配比较判断。
