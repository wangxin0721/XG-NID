## 1. 研究定位与范围

研究主线：**原始 XG-NID → 双分支异构图编码 → 自适应门控融合 → 有证据的模型改进 → 小论文**。

| 方向 | 本篇定位 |
|---|---|
| 原论文 XG-NID Edge 复现或可审计重实现 | 早期核心任务，建立原始方法参考 |
| 冻结分组 E0～E3 | 必须完成，为模型比较提供统一受控基础 |
| 双分支编码结构优化 | 主要候选：提高有用差异与互补性 |
| 自适应门控优化 | 主要候选：分类语义、预测可靠性与动态融合 |
| 类别不平衡、困难类别特定机制 | 辅助方向，基础机制确认后才决定 |
| 新图构建、新关系、可学习 Flow–Packet 关联权重 | 本篇暂不开展 |
| 实时检测或部署系统 | 本篇暂不开展；计时仅作计算开销评估 |

保留现有 Flow–Packet contain、reverse contain、Packet–Packet link、节点特征及边属性。创新阶段不改变图拓扑、边关系定义或已有输入清单；编码器内部的分支投影/编码模块可在新版本研究。两个候选方向不预设都要实现，每轮仅修改一个主要机制。

暂定题目：《基于双分支异构图神经网络与自适应门控融合的网络入侵检测方法研究》。只有可靠性机制获得证据支持后，再考虑“可靠性感知”题目，不提前作贡献承诺。

## 6. 优先审查模型语义与机制（不改冻结训练）

当前源码的初步可见事实，不代表已完成真实检查点诊断：`model.py`将两路64维池化表示投影为8维z；门控用z的Softmax熵/margin和余弦一致性；融合后经过8→32→8的shared_head；`train_grouped.py`直接对最终输出计算NLL，没有独立分支分类损失。未独立监督不等于必然无类别语义，但不能仅凭变量名“logits”认定语义成立。

现阶段论文统一使用“**双分支低维表示的自适应门控融合模型**”；历史类名 `DualBranchLogitGatedHeteroGNN` 及其Edge子类、变量名和配置均不改动。8维z是分类头之前的中间表示，H的输出才是用于最终分类的logits；实际forward另作log_softmax返回NLL输入。后续若研究真正的预测logits融合，应有类别语义明确的分支预测头，并直接融合其分类输出；这是独立新版本，不替换冻结E3。

实际形式：y=H(g_f*z_f+g_p*z_p)，(g_f,g_p)=normalize(0.9*q+0.1*[c_f,c_p])；q为学习门控，c为中间z的熵代理分数。两路都看完整图，不称严格隔离的Flow-only/Packet-only，熵代理也不直接称校准的预测可靠性。

| 审查任务 | 轻量实施与交付 |
|---|---|
| z与shared_head语义 | 在验证集比较原始z、H(z_f)、H(z_p)与最终输出的逐类指标；中间argmax仅诊断；H(z)是联合模型中的单路干预，也不是独立训练基线 |
| 可靠性 | 使用有类别口径的概率评估正确/错误条件下熵、margin、可靠性曲线、Brier/ECE；标注分箱和样本量，不将z代理直接当真实分类概率 |
| 分支互补 | 预测一致率、两路均对/仅一条对/均错四格、分歧子集融合收益；用固定验证样本上的归一化表示相似度/线性CKA辅助分析冗余，不以单一相似度替代互补正确率；任一路对的oracle仅是标签可知诊断上界 |
| 门控行为 | 整体、逐类、正误样本和互补四格的权重分位数/方差/极端占比；均值接近0.5不证明塌缩，偏向强路不自动是错误 |
| 损失和梯度 | 核对编码器、分支投影、shared_head、gate和平滑项的计算/梯度路径；零梯度与未参与图区分，多批次验证 |
| contain正确性 | 核对实际关系入度、自环/dropout、GAT边属性进入位置和池化路径，用小图/真实关系扰动验证单入边Softmax为1的解释；不研究新关系权重 |

现有总体Edge证据不等于每类关系属性都影响输出：Reverse/Link已有扰动与梯度证据，contain的结构性零敏感度需单列说明。正确性审查结果用于解释原模型边界；不把跨粒度关系改造纳入本篇创新路线。

独立导出工具以eval/no_grad重载现有最佳权重，保留sample_id、真值、两路z、H(z)、门控、最终分数。先检查预测与原评估一致、模型状态不变，再全量验证；当前CSV未保存全部分支信息，不假称已有完整诊断。可缓存输出减少重复读取，不为增加日志重训模型。

保留v2的全局固定权重对照：每个冻结检查点在验证集搜索alpha∈{0,0.05,…,1}，按Macro-F1选取；并列先取最靠近0.5，再取较小alpha。使用H(alpha*z_f+(1-alpha)*z_p)，冻结alpha后才评估测试。同检查点的等权/全局固定/动态融合是推断干预，与跨检查点端到端E2/E3比较分开报告。若另训E2-fixed，须同预算对照，不默认启动21次训练。

输入屏蔽仅限验证集敏感性诊断；保留图及未声明屏蔽的输入，说明边属性仍含报文信息和分布偏移。它不能替代从头训练、定义清楚的严格单模态基线。

**容量影响候选对照**：现有冒烟总参数E0=431704、E2/E3=846800，其中休眠门控和辅助头不代表有效预测容量。若双分支表现改善，先比较总参数、有效路径参数及开销；预算允许时另设单编码器容量对照，通过预先固定的宽度调整使有效路径参数尽量接近双分支（目标误差±5%，不可达则报告实际差距），保留同图、同划分、同训练/选模规则。原参考卷积有写死64维的实现，不能直接改E0或仅传hidden参数冒充容量匹配；该对照需独立版本和形状检查。宽度按参数计数选定而非测试成绩选择；同时报告计算开销，因为参数近似相同不等于计算量或归纳偏置相同。本项只做设计，不自动启动训练，也不把E2/E3胜E0直接解释为双分支结构的独立贡献。

## 7. 创新模型设计与验证（独立验收阶段）

优先调查可靠性门控问题，同时保留双分支编码差异化方向；根据验证证据与相关文献只选择一个主要机制。候选不是已确定的方法。

| 候选 | 技术动机 | 最小改动及必须控制的变量 |
|---|---|---|
| A 双分支差异化编码 | 两路冗余或单路质量低，互补不足 | 分支专用投影/差异化编码/轻量监督选一项；不更改原图、边关系或原始特征集合 |
| B 可靠性门控 | 有互补但门控选不对，z代理缺少可靠性证据 | 考虑有明确分类监督的分支预测，或可学习样本可靠性；优先证实语义问题再定结构，不同时重写编码器 |

在首轮E2/E3诊断后、M1实现前登记唯一主方向，按以下验证集证据决策；优先检查B，不预设B有效或新颖：

| 验证集诊断 | 优先行动 |
|---|---|
| 表示相似且互补正确率弱 | 选择A：差异化编码；先确认相似性不是度量或分类头口径造成 |
| 有互补，但在分歧样本上动态融合未利用正确分支 | 选择B：可靠性感知门控，核查可靠性输入和决策目标 |
| z类别语义证据不足 | 先验证分支分类监督与直接预测融合，按单因素对照区分监督和门控收益 |
| E3与等权接近 | 先比较验证集选择的全局固定权重，排除只需整体融合比例调整的情况 |
| E2/E3均明显弱于E0 | 先检查双分支合理性、容量和训练路径，不进入复杂门控开发 |

“高度相似”“互补弱”等描述须报告样本数、逐类计数和度量值，依据预先记录的诊断口径解释；证据不足时补轻量验证，不长期停留在两个方向均待定，也不同时开发两套新模型。

若使用真正分类logits的候选：z_f=H_f(h_f)、z_p=H_p(h_p)，各自有明确分类监督，最终融合输出有清楚类别含义。新增分支监督、移除/替换shared_head、修改融合各自是机制变化，分步实现并配套对照。若比较“可靠性门控”与等权/纯门控，两侧分支监督及其权重必须相同，避免把辅助损失收益归为门控收益。

|---|---|
| M0 | 验证集诊断后预先选定的合理现有基线，固定代码/配置；E0与必要E2/E3作为外部参照保留 |

不为凑消融而同时增加两个模块。第二个模块仅在第一个已明确、且有额外动机时另立版本，形成逐步添加与移除的对照。

M1入围最终确认前交付四项证据：①验证集上明确且可复查的瓶颈与技术假设；②与已有门控/注意力融合方法的具体文献差异；③可独立移除的改动和有效单因素消融；④整体及困难类别收益、参数/计算开销的量化权衡，并具备同协议配对多种子配置与预算。最终验收另须完成⑤预定种子的重复实验，报告均值、波动和配对差值。仅提高Macro-F1不等于完成创新；小幅收益若伴明显成本增加，不直接声称实用优势，改动价值须由技术动机、机制证据和性能/代价共同支撑。未满足时先作诊断或方法调整，不仓促定稿。

决策口径沿用v2的探索性验证Macro-F1阈值：≥+0.3个百分点为优先确认信号，≤−0.5个百分点触发退化检查，绝对差<0.2个百分点为接近，其余灰区；这些不是统计显著性或效果保证。单种子接近仍可做配对重复，不等同无效。

E3胜E2但不胜E0时分析整体竞争力；E2弱于E0时先查双分支质量；两路同对同错时先查冗余；有互补但门控失败时查可靠性/目标。无实现错误后再决定是否改法，每轮最多一个主要变化和两个筛选配置，不大规模搜索。

## 8. 数据、测试使用与文献约束

已有测试WebBased低分仅描述既有基线，不能直接据此增设类别专用结构或选超参数。先在验证集确认同类问题；具体结构、损失、阈值和困难类别策略均以训练/验证证据决定，记录决策日期、版本及测试评估次数。

现有测试已被查看，不称从未接触的最终留出集。新版本在方法和配置冻结后评估，不能反复按测试反馈挑版本；若有可获得的独立外部/场景数据，再另设最终验证任务，不虚构额外数据。文中披露测试访问历史与选择偏差风险。

复用审计SQLite核对Edge/No Edge全量标签冲突计数，不能用“冲突示例为空”代替计数证据；已有构建拒绝组内标签冲突应引用对应检查。检查可恢复的flow/capture ID、时间、设备/会话和预处理来源；缺失则说明。精确输入分组不保证近重复、设备、流或场景独立。

近重复仅作固定抽样、阈值与覆盖率明确的探索审计，尺度仅在训练集拟合，不做全量两两比较，不自动删除相似样本。核对标签列、文件标识与全数据拟合统计是否进入输入。明确泄漏或实现错误时受影响结果另版修复，不能据一般相关性无限推迟研究。

文献工作与P0/P1同期开始，首轮8～12篇最相关原始论文/作者代码：双分支NIDS、异构图编码、表示/预测融合、可靠性与置信度门控。记录输入、融合位置、监督、图关系、协议、开销和与候选的实质差异。普通双分支加门控不预设为创新；相关性与不平衡文献仅用于定位，不扩展成新图关系研究。

保持冻结训练源码和历史目录不变。新增独立评估工具不影响原代码哈希，真实模型/训练逻辑改变另设版本并重做受影响检查，不为继续训练放宽校验。每次命令包含环境、后台启动、PID、实时日志、状态和结果读取；现脚本每轮更新且无resume，批次进度/可靠恢复另版开发。Ctrl+C退出tail不等于训练停止，按进程和状态判断。
