# Packet层内残差：Res-Base／Res-Skip

本轮只回答：在第二层关系消息平均聚合之后、BN和激活之前保留第一层表示，是否优于相同末层投影与训练预算的对照。
本轮不使用注意力池化、关系自适应选择或池化后浅层拼接。

| 项目 | Res-Base | Res-Skip |
|---|---|---|
| 共同起点 | 原D32-Gate第62轮，97.320705% | 相同 |
| 两类关系计算及平均聚合 | 原GAT与原平均 | 相同 |
| 第二层Packet更新 | LeakyReLU(BN(m2)) | LeakyReLU(BN(m2+R(h1))) |
| R | 无 | Linear(64,64,bias=False)，全部权重零初始化 |
| 原编码器、BN参数及统计 | 冻结、eval | 相同 |
| Packet最终池化 | 有序平均 | 相同 |
| 共有末层投影 | Linear(128,64)，输入[h2,h2]，初始化[0,I]、偏置0 | 相同 |
| 原64→32投影、逐维门控、分类头 | 继续训练 | 相同 |
| 可训练参数 | 15,400 | 19,496（额外残差4,096） |

h1指第一层原BN及激活之后的每个Packet表示，m2指第二层原两类关系输出的平均。
残差仅影响报文编码器的第二层Packet目标更新；Flow编码器及其他节点处理保持原定义。
不改变空边关系的原卷积输出／偏置，也不增加掩码。R与后续冻结BN、激活及训练中的末层投影均在梯度范围内。

两组从原D32开始，不能加载CL-Last第113轮或CL-Multi第126轮作为训练起点。
末层投影是两组共有的参数化和训练机会，残差是唯一候选差异。
R的零初始化与共有投影的恒等初始化共同保证第0轮复现原D32预测与混淆矩阵。

## 训练协议

seed42、原固定分组、训练／验证batch512／16、workers2、原最终输出NLL。
新建Adam，WD=0；原投影／融合门控／分类头LR1e-5，共有末层投影LR1e-4，新增R也为1e-4。
两组各固定150轮，31,650次更新；关闭早停。min50和patience20仅沿用记录，不截断训练。
第0轮单独保存并参与最终选择；训练后最佳只从1—150轮选择，最终与第0轮比较，平分保留第0轮。
独立重置优化器、随机状态及采样器，核对全部150轮样本顺序和相同随机起点。

记录epoch_zero.pt、trained_best.pt、best.pt和last.pt，分别报告起点、训练后最佳、最终最佳、末轮和逐类变化。
导出修复／退步样本和预测流向，报告WebBased、Recon、Spoofing、BruteForce的取舍。
候选扩大投入的门槛仍是 `F1(Skip)-max(F1(Base),F1(D32)) >= 0.10个百分点`。
历史CL-Last97.467535%和CL-Multi97.509986%只作分数参考，不替代该轮匹配对照。
不声称统计显著，不评价测试集，不自动追加其他结构或随机种子。
