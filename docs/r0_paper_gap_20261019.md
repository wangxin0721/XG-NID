# R0 与论文97% Macro-F1的差距核查

本次仅阅读论文、源码和已有服务器指标，并对回传数值作算术核对；没有加载模型或图、重新测试或调整训练。R0正常完成和成功复现论文分数是不同验收项。

## 指标口径更正

用户提供的期刊版 `C:/Users/wx/Desktop/XG-NID(科研通-ablesci.com).pdf` 第10页表5、第11页表6列出Proposed Work F1=0.97。更关键的是第11页图5的纵轴明确写着 **Macro F1-Score %**，CIC-IoT2023绿色柱为97%。作者公开预印本对应图5：https://arxiv.org/html/2408.16021v2#S4.F5 。

因此，不能继续声称论文97%的平均方式完全未知。对图5应比较R0 Macro-F1=92.8211%，差约4.1789个百分点；R0 Weighted-F1=95.2727%不是替代比较指标。论文只展示整数百分比，差值为相对图中约97%的近似，不是对作者原始精确预测的重算。

## 已确认：当前低分来自哪里

完整测试混淆矩阵与各项指标算术一致。WebBased F1=71.7791%、Recon F1=90.7767%，是主要弱项；546张Recon被判为WebBased。WebBased召回96.6055%，但1844个WebBased预测中有791个假阳性，精确率57.1041%。宏平均对8类等权，少样本WebBased不会因为只有1090张就被弱化；这解释当前宏平均低于加权平均，但不能据此解释作者为什么能更高。

Mirai/Dos/DDos的F1均超过99.5%，不支持“所有类别都没学会”的描述。上述是当前错误分布的证据，不是模型内在机制或论文差距的因果证明。

## 后续处理边界

保留本次R0为原始Edge协议重实现的真实结果，明确“正常完成，未达到论文报告分数”。优先恢复或核查源CSV列→图特征对应、temporal特征生成参数、MAC过滤/亚类采样和作者论文运行证据；独立推断核查必须另存诊断记录，遵守测试访问记账，不能用测试选择参数。当前没有这些新增服务器证据，不把根因标为已定位。

不因看见差距就修改测试集、反复搜索测试分数、改选更高测试分数的历史轮次，或自动增加epoch/换seed。若后续确认具体实现偏差，修复后建立独立版本并重新做服务器验证。E2/E3继续按已冻结分组协议执行，其结果单独解释。
