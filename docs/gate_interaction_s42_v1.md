# D32-Gate跨分支交互增强配对协议

三组共用D32-Gate第62轮检查点，验证起点为97.320705%。两路编码器及BN固定，训练复用固定分组的Flow和Packet图级64维缓存。配置固定检查点、原预测文件及两份缓存的SHA256，启动时逐项验证，并将缓存中的图ID和标签与原分组清单逐条比较。

| 组别 | 分类头输入 | 可训练参数 |
|---|---|---:|
| D32-Continue | 原逐维加权结果 `z0` | 7,144 |
| Gate-Add | `z0 + 4α(1−α) ⊙ W(U_F z_F + U_P z_P)` | 7,912 |
| Gate-Interaction | `z0 + 4α(1−α) ⊙ W((U_F z_F) ⊙ (U_P z_P))` | 7,912 |

两种新分支共用相同的随机初始投影。`U_F`、`U_P` 为32→8，`W` 为8→32，全部无偏置，共768个参数。`W` 从零开始。原门控产生的同一个32维 `α` 控制两路加权和新分支的强度。

三组使用seed42、原固定分组、train512、eval16、新Adam、原最终输出NLL和WD0。原融合头学习率为 `1e-5`，新投影为 `1e-4`。每组固定150轮、31,650次更新，第0轮参与选模，同分选更早轮次。服务器入口先验证第0轮与归档D32的全部13,446个验证预测一致，再从相同的三个训练批次检查第一步只有 `W` 获得新增分支的非零梯度和更新，随后两个输入投影也实际更新。探测使用独立副本和Adam。

每组保存第0轮、训练后最佳、最终选中及末轮权重。严格重载选中权重，在完整验证原图回放，逐条核对预测与混淆矩阵。产物包含八类精确率、召回和F1，两两比较的修复和退步样本，以及每轮的采样顺序摘要。数据使用范围为训练和验证分区。

## 判读

主比较为Gate-Interaction相对Gate-Add。预算指标为Gate-Interaction相对D32-Continue和Gate-Add中较强者的增益。

- 增益达到0.10个百分点时，下一轮比较门控调节和固定交互强度。
- 同时超过两个对照且增益低于0.10个百分点时，记录小幅正向结果与逐类得失，后续复现决定贡献定位。
- 仅超过D32-Continue时，新增分支的收益由与原式的比较衡量，乘法的增量由Gate-Add配对结果判定。

单列与CL-Multi第126轮97.509986%和当前最高JCL-Multi第48轮97.524609%的成绩差。门控强度项的独立贡献由后续有门控与固定强度配对估计。[JCL-Multi结果](joint_cross_layer_packet2_results_20261106.md)

## 本地验收

CPU读取原始D32检查点和两份缓存，校验检查点与缓存哈希。三组复现全部13,446个归档预测，零初始化分支与原式的输出和门控权重逐元素相同。真实训练缓存前三批通过分阶段梯度和参数更新检查。合成原图的两轮训练覆盖三组采样顺序、平分选模、检查点重载与原图回放。服务器CUDA预检、150轮训练及完整原图回放由服务器入口执行。
