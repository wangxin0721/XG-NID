# Flow查询报文读出配对实验

两组沿用成熟D32-Gate第62轮，冻结两路编码器和BN。训练复用报文池化确认实验的节点缓存，包括每图64维Flow表示、逐节点64维Packet表示、图边界和标签。入口校验原检查点、原预测文件和两份节点缓存的SHA256，并逐图核对固定分组清单中的ID、标签及顺序。[原报文池化确认](packet_pool_confirmation_s42_v1.md)

| 组别 | 查询输入 | 键及池化值 | 新增参数 |
|---|---|---|---:|
| Mean-Query | 当前图内的Packet节点均值 | 当前图的Packet节点表示 | 1,024 |
| Flow-Query | 同一图的Flow分支64维表示 | 当前图的Packet节点表示 | 1,024 |

两组用同一结构和初始权重。无偏置查询投影与键投影均为64→8。对于图 `g` 的报文节点 `i`，分数为 `q_g·k_i/√8`，在该图内做softmax，再按注意力权重池化64维Packet节点。池化输出和原Flow表示接入D32逐维门控与共享分类头。两个分支之间唯一的实验变量是查询输入来源。

查询投影从零开始，键投影使用seed42的相同初始权重。均匀注意力时，使用原报文池化实验的有序分段均值和中心化修正，使第0轮池化逐元素等于有序均值。训练前核对全量验证预测与归档D32一致。三个相同训练批次的探测检查首步更新查询投影，随后键投影也更新。单报文图的权重为1。

两组各8,168个可训练参数。沿用seed42、固定分组、train512、eval16、新Adam、原最终输出NLL及WD0。D32投影、门控和分类头学习率为 `1e-5`，新读出为 `1e-4`。各跑满150轮和31,650次更新，第0轮参与选模，同分保留较早轮次。两组逐轮核对采样顺序，按组检查冻结编码器与BN哈希。

训练完成后严格重载最佳检查点，以原验证图逐条核对预测及混淆矩阵。导出两组逐图Packet注意力、Flow门控权重、八类指标及配对变化记录。预先指定WebBased、Spoofing和Recon，按真实类别分别报告修复和退步。

主结果为 `Flow-Query−Mean-Query` 的验证Macro-F1百分点差。JCL-Multi第48轮97.524609%作为单独的最高成绩参照。[JCL-Multi结果](joint_cross_layer_packet2_results_20261106.md)
