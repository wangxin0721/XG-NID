## 构图

一行一个流图，Flow 1 个节点，82 维（97 列减十四个报文列和 Label）；Packet 为 13 个元信息 + 1500 payload 字节，共 1513 维。13 个元信息为方向、IP/传输/载荷大小、delta time、8 TCP flags。payload 截断/补齐到 1500 字节是现有构图行为。

Contain 为 flow 0 到每个 packet；Reverse Contain 为对应索引翻转，属性仍描述同一个报文，方向不额外取反；Link 仅为相邻 packet i 到 i+1 的有向链，不添加反向 Link。

Contain/Reverse 属性 float32，4 维：[packet_direction, ip_size, transport_size, payload_size]。Link float32，1 维，来自 delta_time[1:]。提取器直接保存 NFStream packet.delta_time；代码中 size 保存 NFStream 对应属性，不能将 transport_size 擅自解读为纯传输层头长。现有字段支持重建这些属性，没有使用伪造边属性填空。没有额外边归一化。

原构图有空 Packet 特征宽度 1508/实际1513不一致和空 Contain 属性形状问题；最小修正为1513和(0,4)。受控入口对缺失/错长列表和非有限图数据报错。

## 原始实现与当前项目

参考 HeteroGNN_Edge 为两层 HeteroConv/GATConv，edge_dim=-1、无自环；forward 将关系属性字典作为第三个位置参数传入两层。当前环境 PyG 2.6.1 实际源码支持此调用及 edge_attr_dict 关键字调用。各关系独立 lazy 投影允许4/4/1维。参考 HeteroGNN 使用 SAGE：原 Edge/No Edge 比较改变了网络层，不能当严格消融。

当前 *_edge 模型确实将属性传入 GAT；非 edge 名称使用 SAGE 并忽略属性。之前缺失属性时会静默退化为无属性 GAT，已改为 Edge 模式报错。当前 encoder 原先重建反向索引并复用正向属性，现改为读取各关系的实际 store，并核查维度。

当前 paper/edge baseline 与参考还存在关系聚合 mean vs 默认 sum、预测头额外 LeakyReLU、可变 hidden_dim 等差异。因此受控 E0/E1 直接包装 vendored 原始 Edge 类，不将当前自定义类称为原始实现；仅适配 batch API 和 None 属性开关。

所有双分支都让两个独立参数的异构编码器接收完整图，再分别池化 Flow/Packet，不是严格隔离 Flow-only/Packet-only。

历史 dual_edge 是拼接嵌入预测；dual_gate_logit_edge 含分支分类器、shared head、额外二分类头；默认训练入口还带辅助权重、hard negative 和门控后校准，不能直接归因于门控。受控链使用同一 logits 模型的等权融合 E2 对比自适应门控 E3，所有额外损失与校准关闭。保留旧入口行为，只新增独立实验入口。

## 后续最小修改与执行门槛

1. 包装原始 Edge，E1 仅传 None 边属性，保留 GAT 和所有边；初始化时先共同物化 lazy 参数，再恢复属性开关，避免初始化差异。
2. 为现有 logits 融合增加固定等权开关；Edge encoder 明确属性开关、逐关系检查。
3. 独立 prepare/smoke/train 入口，保留源哈希、稳定 row ID、内容哈希、标签映射、固定 split、代码哈希、退出状态和日志。新小规模数据不替代旧实验。
4. 先验证真实图前向、属性敏感性、有限损失和梯度、更新以及配对初始参数完全相同。
5. P2/P3 正式全量训练暂受数据身份/泄漏问题阻塞；允许小规模链路试运行，结果不得作为论文性能证据。

GAT 的属性仅作用于归一化注意力；此拓扑的 Contain 和 Link 目标各仅一条入边，因此即使正确传入，改变这些属性也可能没有数值影响。Reverse Contain 汇入多个报文时可验证属性效应。不得将“传入每个关系”表述成“每个关系都增加了有效信息”。
