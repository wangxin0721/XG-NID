# Rel-Mean／Rel-Gate：第二层Packet关系选择

仅实施这两组，均从原D32-Gate第62轮最佳权重开始，验证Macro-F1=97.32070542814468%，SHA256=`7815875a111d3e94ceefd0e9ef6cb64dedaf6ff80723645f1ec035b376af31ff`。不使用池化候选权重或J32权重，不改历史模型、配置、结果。池化实验只能说明原20轮筛选协议下没有获得收益，不能证明继续训练一定无效。

Rel-Mean保留关系平均。Rel-Gate只改变报文分支第二层、指向Packet的Flow→Packet及Packet→Packet聚合：评分输入为目标Packet第一层表示和两路第二层关系输出，拼接192维，经Linear(192,16)→LeakyReLU→Linear(16,2)→Softmax，每节点两权重和为1。新增3,122参数，Rel-Mean／Gate可训练参数分别为7,144／10,266。

评分末层weight／bias均为0，初始权重0.5／0.5。用原 `torch.stack([mF,mP],dim=0).mean(0)` 加中心化注意力修正，初始修正为零；其后原第二层BN及激活仍在梯度范围内。所有旧GAT、BN参数和缓冲区冻结，所有编码器子模块保持eval；新评分、原投影、32维融合门控和八分类头参与训练。Flow分支、第一层、Packet→Flow和最终Packet平均池化均沿用原数学处理；图读出使用已登记的有序分段mean后端。

## 保留空关系与重新缓存

临时pre-hook捕获Packet第一层表示，第二层两条关系卷积的forward-hook捕获原始输出。原HeteroConv、GAT、边属性传递和空边调用流程照常执行；hook不替换返回值，并在成功／异常时清理。[PyG 2.5.3 HeteroConv源码](https://pytorch-geometric.readthedocs.io/en/2.5.3/_modules/torch_geometric/nn/conv/hetero_conv.html)

零条边仍会调用关系卷积，可能返回带bias的向量；原模型会把它纳入平均。本轮不增加边存在掩码、不强行把输出置零、不省略该关系，也不改变缺失关系键原本的报错行为。

必须重新读取训练／验证原图，缓存每Packet的第一层64维、两路第二层各64维聚合前输出，另存Flow图向量、旧Packet图向量用于诊断、指针、标签及边覆盖信息。旧池化节点／图缓存都不能替代这些关系输出。缓存常驻CPU，训练按图抽样后转GPU；加权、第二层BN／激活、平均读出及下游保持梯度。

`relation_diagnostics.json`按划分及八类报告两消息范数、差值L2、相对差异、余弦、空关系图数、无入边节点数和零范数节点数。范数与相似度按Packet节点平均，不与按图平均混淆。原消息平均经BN／激活必须在1e-6内复现同一次原始编码结果。缓存拼接前输出实际总节点数、张量大小和双份拼接峰值，计入已驻留另一份缓存，估算不等于进程RSS。

## 启动前登记的训练／选模规则

seed42、原分组；Adam新建、WD0、原最终NLL；原投影／融合门控／分类头lr1e-5，新关系网络lr1e-4；train/eval batch512/16。登记最少50轮、最多150轮；两组均固定跑满150轮，禁用早停。patience20仅保留为历史兼容／进度计数设置，不会截断训练。

第0轮完整评价并独立保存 `epoch_zero.pt`，只作为最终保留模型的成熟起点。早停最佳值从负无穷开始，仅比较第1轮及以后；训练后最佳严格改善便重置stale，即使低于第0轮。stale只用于描述训练进展，不触发停止。最终在第1—150轮全程选择训练后最佳；每组150轮、31,650次正式Adam更新。最少50轮是登记下限，实际固定150轮；这消除了提前早停截断本轮计划窗口的影响，但不保证提分或排除150轮之后的变化。

`trained_best.pt`独立保存最早取得训练后最高验证Macro-F1的检查点；`best.pt`比较第0轮与训练后最佳后保留较高者，相等时保留第0轮。另保存 `last.pt`。明确分别报告第0轮、训练后最高及轮次、最终选中值及轮次和末轮；不将第0轮作为patience参照。训练后最佳也导出独立逐样本预测及全类别指标。

## 阻断式验收

1. 来源与成熟权重SHA、标签、划分、编码器状态及公共权重严格核对；CUDA合成关系均值／0.5权重、冻结BN后的反向先通过。
2. 先完成原始关系差异／范数／空关系诊断；完整验证P0式数值边界：Rel-Mean／Gate及同一冻结消息下的源读出atol/rtol=1e-6，成熟D32逐样本预测及CM完全一致。独立旧CUDA全图log误差另记，不冒充严格同输入数值一致。
3. 两组各3次真实图废弃更新；新评分输出层和隐藏层连续窗口中有有限梯度及实际参数更新，关系权重偏离0.5。允许隐藏层第一步梯度为零。所有旧编码器和BN保持冻结，原图／缓存输出1e-5一致。完成或异常均恢复模型、梯度及Python／CPU／CUDA RNG，探测Adam丢弃。
4. 干净预检检查点严格重载；两组分别重置正式Adam和训练RNG，校验共同轮次样本顺序。
5. 最终选中和训练后最佳检查点分别严格重建，在全部13,446张原验证图上回放；若二者为同一轮且完整状态摘要相同，可共享同一次完整回放收据，不能重复计算加载次数。
6. 训练结束核对缓存／源产物SHA、冻结参数／BN、共同顺序；通过后才写completed。失败保留failed及error.log，不自动重试或启动后续模型。只允许训练／验证图，测试图拦截保留。
