本轮残差收束。保留CL-Multi第126轮（97.509986%）为当前最高验证候选，D32-Gate为历史基线。
初始准备提交只提供算子对照模型、真实张量测试和小规模原图训练探测。
服务器已报告原图CUDA探测成功；正式训练入口与启动方式见[150轮执行协议](attention_operator_training_s42_v1.md)，运行前仍须校验服务器完整探测收据。

## 问题与初始化

问题是改变邻居注意力算子是否优于本轮重新训练的GAT。两组全部从头初始化，不使用成熟GAT、GATv2或其他候选检查点。
这属于重新训练双分支模型，不能与此前冻结编码器的筛选直接等同。

对应的源／目标节点投影、边投影、输出偏置、BN、64→32投影、逐维动态门控及八分类头使用相同的具名CPU随机流。
初始化审计比较全部可对应参数与缓冲区，逐张量完全相等。两组各自注意力参数的形状／含义不同，分别使用具名随机流；不强求初始预测一致，不把同seed误称为同算子起点。
初始化、探测均记录种子；训练样本次序需另用独立采样器，不依赖模型构造消耗的随机数。

## 共同结构

- 两个独立编码器，各两层、64维、单头，原三种关系和4／4／1维边属性。
- 两层都替换算子；异构关系固定mean，最终节点固定mean池化。
- 原BN eps=1.0和LeakyReLU。两组从干净BN统计开始，训练期间正常更新。
- attention negative_slope=0.2、dropout=0，无自动自环；GATv2不共享源／目标权重。
- 后端为原D32的64→32双投影、32维逐维动态门控及八分类头；不加CL-Last投影、残差、注意力池化或关系选择。

PyG2.5.3的GAT源／目标Linear没有内部偏置，但GATv2默认具有内部偏置。
为避免额外引入这一差别，MatchedGATv2Conv调用原生GATv2(bias=False)，再恢复与GAT相同的最终64维输出偏置。
测试逐数值比较该实现和内部偏置置零的原生GATv2；不是另外重写注意力公式。
GAT每个关系有att_src、att_dst、att_edge，GATv2为单个att，故两分支共12个卷积的GATv2少1,536个参数。
这是算子固有参数化差异，报告实际参数量，不人为增加无用参数。
在原Flow82／Packet1500输入下，GAT共851,688个参数，GATv2共850,152个参数；所有参数允许训练，但计算图中未用于所选分支输出的参数可能没有梯度。
历史model.py不修改；GAT对照的编码器和原定义严格加载、前向一致性有专门测试。

源码依据：[GATConv 2.5.3](https://pytorch-geometric.readthedocs.io/en/2.5.3/_modules/torch_geometric/nn/conv/gat_conv.html)、[GATv2Conv 2.5.3](https://pytorch-geometric.readthedocs.io/en/2.5.3/_modules/torch_geometric/nn/conv/gatv2_conv.html)。

若探测存在非有限数、OOM或参数未更新，应先修正问题并更新登记；不自动缩小一组batch或改变一组学习率。

## 探测范围与验收

先运行7项真实torch／PyG测试：配对初始化及RNG、原GAT兼容性、GATv2偏置匹配、全部关系边属性的前向影响及梯度、单报文／空关系、探测恢复及异常恢复。
本地7项均通过，合成图CPU探测也通过；完整收据见[本地验证记录](attention_operator_pair_local_validation_20261104.json)。原图与CUDA探测需在服务器执行，当前不声称已经通过。
然后按冻结manifest逐样本校验加载每类64个训练图（共512）及每类2个验证图（共16），两组使用相同图和顺序，各执行3次Adam更新。
不加载测试图，不加载冻结表示缓存，不将这16个图的成绩当作完整验证成绩或选模依据。
原图选择、源码哈希、设备、版本、参数量、梯度、参数／BN变化、每步时间及CUDA峰值分配内存写入probe.json。
旧编码器存在一些不影响所选分支读出的关系参数；不要求每个存储参数都具有非零梯度，但两分支及融合头都必须有非零有限梯度。
只含一个入邻居的节点，softmax注意力为1，边属性或注意力梯度可能为0；合成多邻居图另行验证算子确实接通边属性。
每组探测后恢复全部权重、BN与随机状态，清除梯度、丢弃Adam状态；正式训练必须重新创建模型及优化器。
成本是3次更新（包含新Adam分配）及小验证集前向；额外报告探测前常驻分配内存，不能据此直接声称150轮完整运行耗时或推理性能。

## 结果与门槛

正式报告必须有两组第0轮、训练后最佳、最终选中、末轮及对应轮次，完整八类P／R／F1、混淆矩阵与修复／退步样本。
必须核对两组150轮样本顺序、严格重载最佳权重并在完整原图验证集回放，报告训练时间与峰值显存，不自动评价测试集。

主要算子差值为`F1(GATv2)-F1(GAT)`。
保留原预算规则：`F1(GATv2)-max(F1(GAT),F1(D32)) >= 0.10个百分点`才考虑扩大投入。
另报告`F1(GATv2)-97.509986%`，判断是否超过当前CL-Multi；预算筛选与历史最高成绩比较分别呈现。
单seed筛选不支持统计显著性声明，不自动追加随机种子或组合前面模块。
